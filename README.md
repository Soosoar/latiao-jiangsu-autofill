# 辣条姐姐<sup>©</sup>江苏事业单位报名助手

🍬 来帮你把报名材料整整齐齐地填好！

这是一个非官方 Chrome 扩展，适用于江苏省事业单位公开招聘平台“省直／省本级”的高校与科研院所招聘岗位，帮助用户整理、填写报名信息，并批量处理证明材料。

## 适用范围

- 江苏省事业单位公开招聘平台
- “省直／省本级”招聘岗位
- 主要面向高校、科研院所招聘
- 使用前需要先登录报名平台
- 填写完成后需要用户自行核对最终信息

## 主要功能

- 一键填写个人报名信息
- 自动填写考生简历、奖惩情况和科研成果
- 自动填写家庭成员信息
- 支持证明材料整理与批量上传
- 图片、PDF 上传前自动压缩
- 无法继续压缩或仍不符合要求时生成提示报告
- 支持资料导出、导入和备份
- 支持一键清除全部资料
- 支持虚构演示资料导入

## 安装方法

1. 在 GitHub Releases 中下载：

   `latiao-jiangsu-autofill-v1.4.1-share.zip`

2. 将 ZIP 文件解压。

3. 解压后，文件结构大致如下：

   ```text
   latiao-jiangsu-autofill-v1.4.1/
   ├── latiao-jiangsu-autofill/      ← Chrome 中需要加载的文件夹
   │   └── manifest.json
   ├── latiao-demo-profile.json      ← 虚构演示资料
   ├── 使用教程.html                 ← 浏览器打开
   └── 使用教程.txt                  ← 记事本打开
   ```

4. 打开 Chrome，在地址栏输入：

   `chrome://extensions`

5. 打开右上角的“开发者模式”。

6. 点击“加载已解压的扩展程序”。

7. 选择包含 `manifest.json` 的内层文件夹：

   `latiao-jiangsu-autofill-v1.4.1/latiao-jiangsu-autofill/`

不要选择最外层文件夹，也不要选择 ZIP 文件本身。

## 使用方法

1. 登录江苏省事业单位公开招聘平台。
2. 打开插件的“选项”页面。
3. 编辑个人资料，或者导入资料备份。
4. 如果只是体验插件，可以导入外层的 `latiao-demo-profile.json`。
5. 打开报名页面。
6. 点击“一键填写个人信息”。
7. 仔细核对网页内容，并点击报名网站自身的“保存”或“确认”按钮。
8. 如需上传证明材料，先在插件中准备材料，再点击“一键上传证明材料”。
9. 上传完成后，检查报名网站中的材料名称、类别和数量。

## 报名系统默认提供的信息

以下实人认证信息由报名系统根据当前登录账号提供，插件不会主动填写或修改：

- 姓名
- 证件类型
- 证件号码
- 性别
- 出生日期
- 移动电话

如果网页中已经显示这些信息，请以报名系统显示的内容为准。

其他报名字段需要根据个人情况在插件选项页中填写，例如民族、政治面貌、考生身份、教育经历、家庭成员、奖惩情况和科研成果等。

## 证明材料处理

插件支持整理并批量上传以下材料：

- 身份证件
- 学历证书
- 学位证书
- 工作经历证明
- 奖惩证明
- 党员证明
- 论文及其他岗位要求的材料

插件会在上传前自动压缩图片和 PDF。对于无法继续压缩或压缩后仍不符合网站要求的文件，插件会在运行报告中提示。

最终请以报名网站显示的上传结果为准。

## 资料备份与清除

- 使用“导出资料备份”保存当前资料。
- 更换电脑或重新安装插件后，可以使用“导入资料备份”恢复资料。
- 使用“一键清除全部内容”可以删除插件中保存的资料。
- 虚构演示资料仅用于体验和录制演示视频。
