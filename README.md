# 辣条姐姐<sup>©</sup>江苏事业单位报名助手

🍬 来帮你一键填表啦！

这是一个非官方 Chrome 扩展，适用于江苏省事业单位公开招聘平台“省直／省本级”的高校与科研院所招聘岗位，帮助用户快速整理并填写报名材料。

## 适用范围

- 江苏省事业单位公开招聘平台
- “省直／省本级”招聘岗位
- 主要面向高校、科研院所招聘
- 需要用户先登录报名平台，并自行核对最终信息

## 主要功能

- 一键填写个人报名材料
- 自动填写考生简历、奖惩情况和科研成果
- 自动填写家庭成员信息
- 支持证明材料整理与批量上传
- 支持材料上传前压缩
- 支持资料导出、导入和备份
- 支持一键清除全部资料
- 支持匿名虚构资料演示

## 安装方法

1. 下载本项目文件并解压。
2. 打开 Chrome，进入：

   `chrome://extensions`

3. 打开右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择解压后的插件文件夹。

请选择包含 `manifest.json` 文件的文件夹。

## 使用方法

1. 登录江苏省事业单位公开招聘平台。
2. 打开插件的“选项”页面。
3. 填写或导入个人资料。
4. 打开报名页面。
5. 点击“一键填写个人信息”。
6. 核对页面内容后，再点击报名网站自身的“保存”或“确认”按钮。
7. 如需上传证明材料，先在插件中准备材料，再点击“一键上传证明材料”。

## 重要说明

- 姓名、证件类型、证件号码、性别、出生日期和移动电话等实人认证信息，默认由报名系统提供，插件不会主动修改。
- 插件填写完成后，请务必逐项核对报名页面。
- 插件不能代替用户完成实人认证、登录验证或最终提交。
- 上传材料时，请注意报名网站规定的文件格式和大小限制。
- 证明材料应由用户自行准备，并确认内容真实、有效。
